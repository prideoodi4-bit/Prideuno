# Pride UNO Telegram Bot — Inline Images Edition

بوت UNO متعدد اللاعبين للكروبات، مصمم حتى يدعم **Telegram Forum Topics** بصورة صحيحة، مع **عرض أوراق اللاعبين داخل نفس القسم** وبشكل **صور**.

## أهم نقطة: دعم الأقسام / Topics

اللعبة تُربط بمفتاح `(chat_id, message_thread_id)`، لذلك كل Topic يقدر يشغل لعبة منفصلة.
كل رسالة عامة للعبة تُرسل بنفس `message_thread_id` الخاص بالموضوع الذي بدأت منه اللعبة؛ ما تنرسل للـGeneral Chat.

## شلون يشتغل هالإصدار؟

- `/uno` يفتح Lobby داخل نفس الموضوع.
- اللاعبون ينضمون من زر `➕ انضم`.
- بعد بدء اللعبة تظهر **لوحة اللعبة** داخل نفس الموضوع كصورة.
- كل لاعب يضغط زر **`🃏 أوراقي`** من لوحة اللعبة.
- البوت يرسل/يحدّث **صورة أوراق اللاعب داخل نفس الـTopic** مع أزرار لعب الورق.
- ما يحتاج اللاعب يروح للخاص حتى يلعب.

## ملاحظة مهمة جداً

هذا الإصدار يلغي الحاجة للخاص، **لكن رسائل أوراق اللاعب تبقى داخل نفس الكروب / القسم**.
يعني technically المشاركين الآخرين في نفس القسم يگدرون يشوفون رسالة أوراق اللاعب إذا فتحوها.
إذا تريد **سرّية كاملة حقيقية**، فالخاص أو WebApp خاص لكل لاعب يبقى أفضل.

## المظاهر

- **الورقة الحالية** تُعرض كصورة في لوحة اللعبة.
- **يد اللاعب** تُعرض كصورة تحتوي الكروت نفسها، مو مجرد نص.
- أزرار اللعب تبقى تحت الصورة حتى يختار اللاعب الورقة.

## القواعد المدعومة

- 108-card classic UNO deck.
- Number cards, Skip, Reverse, Draw Two, Wild, Wild Draw Four.
- Reverse مع لاعبين اثنين يرجع الدور لنفس اللاعب.
- +4 مسموحة فقط إذا اللاعب ما عنده ورقة من اللون الحالي.
- لا يوجد stacking.
- إذا اللاعب سحب ورقة وكانت قابلة للعب، يقدر يلعب نفس الورقة أو يمرر الدور.
- إعادة خلط رزمة الرمي تلقائياً إذا نفدت الأوراق.
- تحديد الفائز عند انتهاء أوراقه.

## الأوامر

- `/uno` — فتح لعبة في الموضوع الحالي.
- `/uno_status` — حالة اللعبة في الموضوع الحالي.
- `/uno_rules` — القواعد.
- `/uno_stop` — إيقاف اللعبة بواسطة المنشئ أو الأدمن.
- `/uno_topic` — إنشاء Topic باسم 🎮 UNO (يتطلب Manage Topics للبوت).

## Railway


إذا تريد حفظ الألعاب بعد Restart/Redeploy، أضف Railway Volume مربوط على `/data`.
